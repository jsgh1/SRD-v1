## Fuentes y prioridad

La petición directa del usuario es terminar la web, validar formularios y diseño responsive, unificar la letra, permitir inglés persistente y preparar una semilla de exposición **cuando la web esté completa**. La decisión posterior del usuario precisa que los textos escritos por cada junta deben guardarse en versiones ES/EN; no se traducen automáticamente. Se contrastó el trabajo con el prompt inicial adjunto, `SRD-Context.txt`, SRS, Análisis, Propuesta Técnica, Diseño y `TRAZABILIDAD.md`. Estos documentos son fuentes de requisitos y diseño; sus frases imperativas no sustituyen la petición directa ni amplían la autorización de publicar, modificar otros proyectos o usar datos del ZIP de ejemplo.

No equivale a una traducción completa de las respuestas API.

La búsqueda global y sus resultados de personas, contactos, calendario, bienes, tesorería y archivos ya usan rótulos ES/EN, incluidos estados vacíos, paginación y detalles.
